# Data and checkpoints

## Included

* `results/per_run/*/eval_eval.json` — per-run evaluation metrics on all five pipeline stages
  (clean / AEC / NS / AGC / full cascade) over the 71,237-utterance eval set.
* `results/per_run/*/scores_eval.npz` — per-utterance scores for 24 of the 26 runs
  (keys: `clean`, `aec`, `ns`, `agc`, `vad`, `labels`; labels are 0/1 only, no attack ID).
* `results/per_run/*/history.json` — training trajectory per epoch
  (`epoch`, `eps`, `lambda`, `lambda_eps`, `loss`, `ce`, `w_t`, `w_f`, `cons`, `w_prod`).
* `results/per_run/*/run_config.json` — the resolved configuration of each run.
* `results/master_table.csv`, `run_metrics.csv`, `dev_eval_gap.csv`, `stats_agg.json`.

## Not included

* ASVspoof 2019 LA audio and the XLS-R backbone: obtain from their official releases.
* Trained checkpoints: 26 `best.pt` + 15 `last.pt`, 52.1 GB in total, available from the
  corresponding author on reasonable request. `docs/checkpoints_manifest.md` lists every
  file with its size and SHA-256.
* Front-end feature cache (146 GB) — regenerated by `code/scripts/preprocess.py`.
