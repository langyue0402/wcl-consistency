## 1. 三臂主结果（各 5 seed，50 epoch，每 run 独立按初始 CE/W 重标定 λ）

| 臂 | seed 0 | seed 1 | seed 2 | seed 3 | seed 4 | 均值 | 标准差 | 跨度 |
|---|---|---|---|---|---|---|---|---|
| CE（双视图交叉熵） | 4.1752 | 4.0139 | 2.8861 | 4.5464 | 3.8645 | **3.8973** | 0.6196 | 1.6603 |
| WCL（本方法） | 4.2391 | 3.5451 | 3.6626 | 4.3083 | 3.9254 | **3.9361** | 0.3384 | 0.7632 |
| TFCL（余弦+CKA） | 3.0010 | 3.0990 | 2.9800 | 5.0613 | 4.4675 | **3.7218** | 0.9757 | 2.0814 |

排序：TFCL 3.7218 < CE 3.8973 < WCL 3.9361。**差值 0.04–0.21，全部小于各自的 seed 跨度（0.76–2.08）。**

### 1.1 配对检验（同 seed 配对，df = 4）

| 对比 | 配对差均值 | 差的标准差 | t | bootstrap 95% CI |
|---|---|---|---|---|
| WCL − CE | +0.0389 | 0.4689 | 0.185 | [−0.316, +0.431] |
| WCL − TFCL | +0.2144 | 0.8410 | 0.570 | [−0.424, +0.858] |
| CE − TFCL | +0.1755 | 0.8215 | 0.478 | [−0.448, +0.817] |

**三条区间全部跨 0 → 三臂统计上不可区分。**这是本 campaign 最重要的负面结论，也是论文必须如实写的部分。

### 1.2 需要多少 seed 才能分辨这些差（功效估算）

- 若真实差 = 0.214（WCL−TFCL），配对差 SD = 0.841，取 power 0.8、α 0.05：n ≈ 8(SD/δ)² ≈ **123 个配对 seed**。
- 若真实差 = 0.039（WCL−CE），SD = 0.469：n ≈ **1150 个 seed**。

结论：在这种单 seed 波动量级下，靠加 seed 去"证明谁更好"在经济上不可行。**论文应改为报告分布与区间，而不是报告一个排名。**

## 4. α（强度）支线

| run | α | λ_eff | avg EER | 备注 |
|---|---|---|---|---|
| `wcl_a0.1__s0` | 0.1 | 0.2128 | 3.9937 | w_prod 末端 0.4014 |
| 主臂 5 seed | 0.3 | 0.4571–0.6900（均值 **0.5918**，跨度 1.51 倍） | 3.9361 | — |
| `wcl_a1.0__s0` | 1.0 | 2.1282 | 3.3725 | n=1 时曾是最低点 |
| `wcl_a1.0__s1` | 1.0 | 2.2865 | 4.2483 | 第二个 seed 把"最强=最好"打回 |

α=1.0 两点：**3.3725 / 4.2483 → 均值 3.8104、跨度 0.8758**。
- 均值只比 WCL 五 seed 均值好 0.126，**仍差于 TFCL 均值 0.088**；
- 跨度 0.876 ≈ 主臂跨度 0.763，说明 α=1.0 并没有带来质的差异，只是抽到了两个不同的 seed；
- 同 α 的两次 run 的 λ_eff 差 **7.4%**（2.1282 vs 2.2865）；更严重的是 α=0.3 的五个 seed 落在 0.4571–0.6900，**跨度 1.51 倍** → **"α 相同 ⇒ 强度相同"不成立**，论文只能把 α 当目标比值、强度一律报 λ_eff。
- α 三点均值 3.994 / 3.936 / 3.810 **非单调也不显著**，不可写"强度越大越好"。
- 图：`figs/fig5_alpha.png`。

### 4.1 关键机制发现：约束项是"饱和"的，不是"越强越好"

末轮 `w_prod` 汇总（λ_eff 跨 10.7 倍）：

| run | λ_eff | w_prod(ep1) | w_prod(ep25) | w_prod(末轮) |
|---|---|---|---|---|
| a0.1 | 0.2128 | 0.7796 | 0.6597 | 0.4014 |
| 主臂 s2 | 0.4872 | 0.7734 | 0.6533 | 0.3940 |
| 主臂 s0 | 0.6385 | 0.7734 | 0.6516 | 0.3915 |
| 主臂 s3 | 0.6900 | 0.7716 | 0.6510 | 0.3910 |
| a1.0 s0 | 2.1282 | 0.7667 | 0.6454 | **0.3846** |
| a1.0 s1 | 2.2865 | 0.7673 | 0.6459 | **0.3851** |
| constprod | 0.639→3.192（λε≡0.319） | 0.7734 | 0.6495 | 0.3852 |
| tonly | 0.7071 | 0.6843 | 0.5344 | **0.2851** |
| fonly | 0.6977 | 0.6988 | 0.4995 | **0.3312** |
| nogeo | 0.5821 | 0.9830 | 0.9151 | **0.8147** |

**λ_eff 从 0.213 到 2.287（10.7 倍），末轮 w_prod 都落在 0.385–0.401（仅 4% 波动）。**
→ 传输残差的下限由**失真几何**决定，不由权重决定；权重只改变下降速度和 CE 的让步程度（a1.0 的 ce 0.061–0.065 略高于主臂 0.052–0.061）。
→ 这条同时解释了：为什么 α 对 EER 几乎无效、为什么 constprod 与主臂同档、为什么"加大强度"无法成为卖点；也给了 §4.4 的 λ/ε 乘积理论一个实证注脚（**在饱和区之外再加权重，只是把 CE 换出去，不换来更多不变性**）。

## 5. dev 选轮偏差（方法学结论，26 个 run 全量）

| 指标 | 值 |
|---|---|
| 样本 | 26 个 run（25 清单 + a1.0 s1） |
| dev best → eval 落差均值 | **+1.81** |
| 中位数 | +1.83 |
| 范围 | −0.20（fonly）～ **+3.74（marginal）** |
| 落差 ≥ +1.0 的比例 | **22/26 = 85%** |
| 落差为负的只有 | fonly −0.20、nogeo −0.18（都是 dev 本身已很高、无"谷底"可乐观） |

明细举例：ce__s0 1.53→4.18（+2.65）、wcl__s3 1.75→4.31（+2.56）、tonly 2.12→5.38（+3.26）、cleanonly__s2 4.09→7.63（+3.54）、a1.0__s1 2.75→4.25（+1.50）、a1.0__s0 2.67→3.37（+0.70，全场最"诚实"）。

**结论：以 dev 平均 EER 挑 best.pt 会系统性高估约 1.8 个点。**这条不只是"我们的注意事项"，而是可以推广的方法学批评：任何用 dev-EER 早停 + 报单次 eval 的鲁棒性论文，其"提升 0.5 个点"很可能只是选轮噪声。
图：`figs/fig2_dev_vs_eval.png`。

## 6. 训练侧与稳定性记录

- 每 epoch：CE 327 s、TFCL 336 s、WCL 系 356 s（纯训练）；墙钟 ≈ 458 s/epoch（TFCL）、8.4–8.6 min/轮（WCL 系，含每 3 轮 dev）。
- 单次 eval 25–65 min 强波动（n=71,237，五相各跑一遍）。
- **掉卡 0 次**（自 11-09 17:03 起至 11-17 09:02，约 184 h），`-rgc` + `-pl 280` 后稳定在 2475–2550 MHz / 277–280 W / 55–63 ℃。
- **训练段错误 2 次**（仅 `wcl_a1.0__s1`）：23:49:58 停 ep20、03:11:24 停 ep35，均为 `pt_autograd_0` 线程 segfault、均落 CPU 9、均发生在 dev 评估轮边界；25 条清单 run 从未出现。处置：只 `--resume last.pt` 续训，不改代码/不改 num_workers；第 3 次尝试（自愈循环 attempt 1）从 ep35 一次跑满 50/50。
- `-pl 320` 不能防掉卡（实测 3 min 就掉）；放开频率是必要决定（锁 1600 MHz 需 190–210 h，超预算）。
- 补算脚本 `_safe_eval.py`（patch `compute_eer` 的 ndim>1）已成功 10 次；`evaluate.py` 的 `compute_eer` bug 与小样本无关、与数据相关（limit=64 时正常 1-D）。

## 7. 一句话版结论（写摘要时可直接用）

> 在同一流水线、同一骨干、同一标定规则下跑完三臂各 5 seed：TFCL 3.72 / CE 3.90 / WCL 3.94（%），三组配对差 0.04–0.21 全部小于 seed 跨度 0.76–2.08、bootstrap 区间全跨 0 → **不可区分**；唯有 AEC 相位 WCL 稳定优于 CE（−0.59，5/5）；VAD 相位为短板（对 TFCL +1.08）。几何代价关闭即崩（13.41）证明几何项必要；而 λ_eff 跨 10.7 倍时末轮传输残差恒为 0.385–0.401，说明约束已饱和、权重不再是有效旋钮。另测得 dev 选轮系统性乐观 +1.81（85% 的 run 落差 ≥ 1），为单 seed 结论提供了一个可推广的批评。
